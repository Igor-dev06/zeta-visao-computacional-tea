# Zeta | Visão computacional e educação inclusiva

Repositório da equipe para o projeto acadêmico **Visão Computacional no Apoio à Educação Inclusiva: Monitoramento de Estereotipias e Sobrecarga Sensorial em Alunos com TEA**.

## Objetivo

Investigar o uso de visão computacional no apoio à educação inclusiva de alunos com Transtorno do Espectro Autista (TEA), conforme a proposta do artigo da equipe.

## Estado do projeto

Repositório em fase inicial de organização. As tecnologias, a estrutura de pastas e as instruções de execução serão documentadas conforme a implementação for adicionada.

## Materiais da equipe

- **Artigo:** projeto compartilhado no Overleaf.
- **Planejamento:** quadro de tarefas no Trello.
- **Histórico de arquivos e colaboração:** este repositório no GitHub.

## Como começar

Após aceitar o convite de acesso ao repositório, faça uma cópia local:

```bash
git clone https://github.com/Igor-dev06/zeta-visao-computacional-tea.git
cd zeta-visao-computacional-tea
```

## Fluxo de colaboração sugerido

1. Atualize sua cópia da branch `main` antes de iniciar uma tarefa.
2. Crie uma branch para a alteração, por exemplo, `docs/descricao-projeto`.
3. Registre as alterações em commits com mensagens claras.
4. Envie a branch ao GitHub e abra um pull request para revisão da equipe.
5. Inclua o link do cartão correspondente do Trello na descrição do pull request.
